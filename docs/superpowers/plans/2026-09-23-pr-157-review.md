## Global Constraints

- Never invoke `cargo` directly. `.\x.ps1 unit-test`, `.\x.ps1 test` and `.\x.ps1 format` are the only entry points. A linker error means a raw `cargo` call slipped in.
- Unit gate (both harnesses): `.\x.ps1 unit-test 2>&1 | Select-String -Pattern "test result:|FAILED|^error|^warning: " | Select-Object -First 20`
- Runtime gate: its exit code is meaningless, so look only for the marker:
  ```powershell
  $output = .\x.ps1 test 2>&1 | Out-String
  if ($output | Select-String -Pattern "Test executed successfully" -Quiet) { "MARKER FOUND" } else { "MARKER ABSENT - relevant output:"; $output -split "`n" | Select-String -Pattern "^error|-->|panic|should" | Select-Object -First 30 }
  ```

    enabling_argument: Option<&SoftDeleteMethodArgument>,
    column_args: &ColumnArgs<'_>,

    // claims the role all the same.
